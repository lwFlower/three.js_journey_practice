## 🧭 About

This repository collects the scenes I built while going through
[Three.js Journey](https://threejs-journey.com/) by Bruno Simon — from the first
rotating cube to materials, lighting and custom shaders.

Outside of this repo, I work with 3D on the web commercially: point cloud
visualization with **Potree**, 3D measurement tools and custom **WebGL shader**
debugging in production projects.

## 📚 Lessons inside

| Topic | Scene | Status |
|---|---|:---:|
| Basics | Scene, camera, renderer, transforms | ✅ |
| Geometries & materials | Textures, matcaps, environment maps | ✅ |
| 3D Text | Font loading, `TextGeometry`, instanced-style scattering | ✅ |
| Particles | | ✅ |
| Shaders | Custom `ShaderMaterial`, GLSL | ✅ |
